# RTTF Tournament Manager: процесс турнира, трудности, справочные материалы

Источник: статьи rttf.ru, разделы 7 «Процесс турнира», 8 «Возможные трудности», 9 «Справочные материалы» (ID 37, 52–60, 72, 74, 78, 38, 73, 65–69, 75, 95, 110, 39, 61–64). Все скриншоты просмотрены. Файлы картинок лежат в `%TEMP%\rttf-raw\img2\<ID>--<name>`.

Обозначения:
- **[факт]**: прямо сказано в тексте или видно на скриншоте.
- **[вывод]**: наша интерпретация по косвенным признакам, требует проверки в живой программе.

Версии на скриншотах: 1.49 → 1.62 → 1.82 → 1.88.0. Номер версии напечатан мелким шрифтом в правом нижнем углу картинок этапов, например `1.88.0`. Меню отличается между версиями:
- старое: `Турнир | Схема | Рейтинг | Экспорт результатов | Настройки | Справка`;
- новое: `Турнир | Схема | Тип турнира | Экспорт результатов | Настройки | Справка`.

Заголовок окна: `Турнир-менеджер RTTF - [1.rttf]*` в старой версии, `цукцукцук.rttf - Турнир-менеджер RTTF*` в новой. `*` означает несохранённые изменения. Файл турнира имеет расширение `.rttf`, тип в проводнике «Файлы турниров». Исполняемый файл: `TournamentManager.exe`.

## 7.1. Онлайн-трансляция на сайте (ID 52)

### Текст
- Онлайн-трансляция показывает текущие результаты на сайте во время турнира. После окончания итоговые результаты остаются на сайте.
- Предусловие: на сайте **должна быть создана страница турнира**.
- Трансляцию можно запустить **на любом этапе** турнира, но **не раньше чем за 1 час до заявленного времени начала**.
- Порядок запуска:
  1. В нижней панели нажать кнопку «задать идентификатор турнира» (шестерёнка).
  2. Ввести ID и нажать OK.
  3. Нажать «начать передачу результатов на сайт» (синий треугольник).
- ID: последние цифры URL турнира. Например, `https://rttf.ru/tournaments/133580` → `133580`. ID также написан на странице турнира: «Идентификатор турнира: 138344».
- Зелёная иконка означает, что трансляция запущена. Турнир появляется в блоке «Турниры LIVE» на сайте, а на странице турнира появляется вкладка **онлайн** с текущими результатами.
- Красный крестик означает ошибку, трансляция не запущена. **Двойной клик по крестику** показывает информацию о проблеме. Если быстро исправить не удалось:
  - отправить итоговые результаты через экспорт (7.11);
  - написать на info@rttf.ru.

  То же делать при сбое онлайна, когда трансляцию нельзя корректно завершить.
- После записи **результата последней игры** через несколько секунд появляется окно «все результаты отправлены», и трансляция **останавливается автоматически**. Итоги с расчётом рейтинга появляются на сайте в течение **5 минут**. Ручной экспорт не нужен.
- **Окно корректировки: 12 часов** от заявленного времени начала. Чтобы исправить результат, нужно снова включить трансляцию, изменить результат и дождаться сообщения об отправке окончательных результатов. Позже исправлять можно только через экспорт с галкой «Корректировка».

### UI (по скриншотам)
- `52--...Скрин1.png`: модальное окно без заголовка с полем «Идентификатор турнира:» (пример `133580`) и кнопками `OK` / `Cancel`. В нижней панели главного окна справа подпись **«Онлайн трансляция:»**, за ней иконка-шестерёнка и синий треугольник «play».
- `52--...Скрин2.png`: страница турнира на сайте.
  - Дата и время, бейдж рейтингового лимита `ОТК` (открытый), название клуба «Оскар», название турнира.
  - Кнопки `РЕДАКТИРОВАТЬ`, `ДОБАВИТЬ ВИДЕО`, `ДОБАВИТЬ ФОТО`, `УДАЛИТЬ ИЗ ЗАКЛАДОК`, `ЗАКРЫТЬ ТУРНИР`.
  - Вкладки `ИНФОРМАЦИЯ`, `ПРОГНОЗЫ`.
  - Строка «Идентификатор турнира: 138344», ниже «ОТК — ограничение по рейтингу», «0 — заявилось 0 чел.», дата и клуб.
- `52--...Скрин3.png`: состояние «идёт трансляция». После шестерёнки стоит синяя иконка **паузы `II`** (кнопка остановки) и **зелёная галка**.

- `52--...Скрин5.png`: страница турнира в режиме онлайн.
  - Кнопки владельца: `РЕДАКТИРОВАТЬ`, `КОПИЯ НА СЛЕД. НЕДЕЛЮ`, `ДОБАВИТЬ ВИДЕО`, `ДОБАВИТЬ ФОТО`, `ДОБАВИТЬ В ЗАКЛАДКИ`, `ЗАКРЫТЬ КОМ-И`, `ОЧИСТИТЬ`, `УДАЛИТЬ`, плюс тумблер.

  - Кнопка «РЕДАКТИРОВАТЬ ССЫЛКИ НА ОНЛАЙН ВИДЕО-ТРАНСЛЯЦИИ».
  - Ниже картинка группы, отрендеренная **той же графикой, что в программе**:

### Механика/правила
- Индикатор трансляции имеет 3 состояния:
  - выключена: шестерёнка + ▶;
  - работает: шестерёнка + `II` + зелёная ✓;
  - ошибка: шестерёнка + ▶ + красный ✗, двойной клик показывает детали.
- Разрешено стартовать не раньше чем за T−1ч до начала. Авто-стоп и финальная отправка срабатывают по записи последнего результата. Финальный расчёт рейтинга занимает ≤5 мин. Правки через онлайн возможны до T+12ч, затем только через экспорт с корректировкой.
- Для трансляции нужны логин и пароль аккаунта представителя клуба в настройках (см. 8.0).
- На сайт уходят картинки этапов и промежуточные расчёты дельт рейтинга (из 8.0).

## 7.2. Настройка народного монитора (ID 53)

### Текст
- Обычно организатор работает с двумя мониторами, например ноутбук и внешний монитор. Второй монитор ставят так, чтобы участники сами смотрели результаты, следующего соперника по сетке, ожидаемую пару и так далее.
- Вывод на второй монитор: в нижней части программы нажать **кнопку с нужным этапом**.
- **Пунктирная область** на основном экране показывает, какая часть сетки видна на втором мониторе.
- Окно **«Народный монитор»** перетаскивают на второй монитор и разворачивают на весь экран.
- **Дельта рейтинга отображается только на народном мониторе.** Его можно сузить и держать поверх основного окна на одном мониторе, чтобы видеть дельты.

### UI (по скриншотам)
- `53--img_content_25_07-004.png`: вкладка этапа «Сетка».
  - Сверху чекбокс **«Скрывать пустые участки сетки»**.
  - Сетка на 8 участников:
    - заголовки раундов в голубых плашках: `1 / 4`, `1 / 2`, `ФИНАЛ`, `3 .. 8`, `3 .. 6`, `3 .. 4`, `5 .. 6`, `7 .. 8`;

    - у каждого игрока справа мелким серым его рейтинг (`R:1408`);

  - **Жёлто-зелёная пунктирная рамка** отмечает видимую на народном мониторе область.
  - Внизу вкладки `Игроки | Сетка | Результаты турнира`.
  - Под вкладками панель: слева **«Второй монитор :»** и кнопка `Сетка` (подсвечена голубым, то есть активна), справа «Онлайн трансляция:» с иконками.
- `53--img_content_25_07-005.png`: отдельное окно **«Народный монитор»** с иконкой ракетки и стандартными кнопками окна.
  - Слева заголовок с названием этапа («Сетка») и сама сетка с полосами прокрутки.

### Механика/правила
- Кнопка для народного монитора есть у каждого этапа. Выбор этапа переключает содержимое окна народного монитора, активная кнопка подсвечена.
- Видимая на народном мониторе область показывается на основном экране пунктиром.
- Масштаб основного экрана и народного монитора настраивается **отдельно** (8.5).
- Дельту рейтинга видно только в народном мониторе (если в настройках включено «Показывать дельту рейтинга»). Список отсортирован по алфавиту, знак выделен цветом.

## 7.3. Вызов встреч (ID 54)

### Текст
- Справа два блока: **«Играется»** и **«В ожидании»**.
- В «В ожидании» лежат игры, которые уже можно вызывать.
- Вызов пары: **клик по свободной паре** (чёрный текст), затем **клик по свободному столу** (чёрный номер).
- **Красным** выделены:
  - ожидающие встречи, где у одного или обоих участников уже есть активная незавершённая игра;
  - занятые столы.
- Другие способы вызова:
  - **двойной клик** по игре в «В ожидании»;
  - клик по игре прямо на картинке этапа.

  Откроется окно выбора стола. **По умолчанию выбран первый свободный стол.** Нажать OK.
- Если по ошибке вызвать две пары на один стол, стол пропадёт из списка выбираемых, а в «Играется» одна из этих встреч будет гореть красным.
- **Стол можно сменить в любой момент встречи** спиннером в окне встречи.

### UI (по скриншотам)
- `54--img_content_25_07-007.png`: блок «В ожидании».
  - Строки вида `Гр(2) | Артеев Т : Муравьев Л`. Метка этапа на жёлтом фоне, выбранная строка синяя.
  - Строки с занятыми игроками красные (`Беляков В : Тарасов А`, `Трегуб А : Зайцев П`, …).
  - Слева столбец «С т о л ы» (вертикальные буквы) и кнопки `1…9`. Занятый стол `8` с красной цифрой.
  - Стрелка показывает «клик по паре → клик по столу 1».
- `54--img_content_25_07-008.png`: блок «Играется». Колонки:
  1. номер стола на светло-зелёном фоне;
  2. метка этапа на жёлтом (`Гр(1)`, `Гр(4)`);
  3. минуты на розовом (`1 м`, `39 м`);
  4. пара `Радченко А : Зайцев П`.

  Две строки со столом `2`: у одной номер зелёный, у второй **красный**, и пара `Беляков В : Тарасов А` тоже красная. Это конфликт стола.
- `54--img_content_25_07-009.png`: окно **«Редактирование встречи»**.
  - Слева вверху **«Стол 8»** со спиннером ▲▼, это смена стола.
  - Справа название этапа «Группы».
  - Ниже имена `Радченко А` и `Зайцев П`, между ними два поля счёта, у каждого свой спиннер ▲▼, поля разделены «:».
  - Кнопки `OK` / `Отмена`.

### Механика/правила
- Очередь «В ожидании» содержит все ещё не начатые встречи, у которых известны оба участника. Встречи с занятыми игроками помечены красными и не вызываются, хотя в списке остаются **[факт по скриншоту]**. Встреча с неизвестным соперником показывается как `??? : Овчаров Д` красным (скрин 72).
- Порядок очереди по скриншотам **[вывод]**: туры чередуются по группам. Сначала 1-й тур во всех группах, потом 2-й и так далее, в каждом туре по номеру группы. Для группы из 3 по скрину 53-006 порядок встреч 1–3, 2–3, 1–2. Порядок встреч внутри группы задаёт параметр схемы «Очередность» (`традиц.` / `ETTU`).
- Столы:
  - количество задаётся в Настройках («Количество столов»);
  - занятый стол показан красной цифрой;
  - стол с двумя встречами исключается из выбора, в «Играется» вторая встреча красная.
- Окно вызова совпадает с окном «Редактирование встречи»: стол по умолчанию первый свободный, OK запускает встречу и стартует таймер.
- Встречу можно вызвать тремя способами:
  1. пара + стол;
  2. двойной клик в «В ожидании»;
  3. клик по встрече на картинке этапа.

## 7.4. Запись результатов встреч (ID 55)

### Текст
- Двойной клик по игре в «Играется» или на картинке открывает окно редактирования результата.
- **Счёт вводится «от проигравшего»**: нажимать стрелку ▲ рядом с **проигравшим**. Для счёта 1:3 нужно **дважды** нажать ▲ рядом с проигравшим (левым). Это минимум кликов.

### UI (по скриншотам)
- `55--img_content_25_07-010.png`: главный экран, этап «Сетка».
  - Встречи 1–4 вызваны, их ячейки на картинке **светло-жёлтые** («Цвет активных игр»), в ячейке счёта красным `4ст` / `5м`, `1ст` / `11м`.
  - В «Играется» колонки: стол | этап `С` (Сетка) | минуты (`11 м`, `6 м`, `5 м`) | пара.
  - Поверх открыто окно «Редактирование встречи»: «Стол 1» ▲▼, этап «Сетка», `Кривошеев В [1] : [3] Ливенцов А`. Поле проигравшего **красное (1)**, победителя **зелёное (3)**. Стрелка указывает на ▲ у левого игрока, затем на `OK`.

### Механика/правила
- Счёт встречи считается в партиях. Победа наступает при количестве партий из настройки «Игра до N побед», по умолчанию 3, то есть до трёх побед из пяти.
- **[вывод]** Нажатие ▲ у игрока A делает победителем B: у B выставляется N партий, у A счёт растёт на 1 при каждом нажатии (первый клик 0:3, второй 1:3, третий 2:3). Цвет фона полей показывает, кто проиграл (красный) и кто выиграл (зелёный).
- Пустые поля на белом фоне означают отсутствие результата.
- Запись результата освобождает стол и обоих игроков. После неё продвигается сетка или пересчитывается группа (О/М), обновляется очередь.

## 7.5. Редактирование и отмена матчей (ID 56)

### Текст
- **Отмена начатой игры**: правый клик по ней → «Отменить игру». Игра возвращается в ожидание.
- **Отмена завершённой игры**: кликнуть на счёт и **обнулить** его тем же способом, каким он выставлялся.
- **Редактирование**: двойной клик по счёту. Затем либо добавить или убрать партии стрелками, либо обнулить, то есть щёлкать до любого сочетания знаков **на белом фоне**, и выставить заново.

### UI (по скриншотам)

## 7.6. Запись технической победы (ID 57)

### Текст
- Если соперники **не сыграли ни одного очка**, ставится **техническая победа**. **На рейтинг она не влияет.** Обозначение `W : L` (победитель : проигравший).
- **Техническую победу или поражение обоим одновременно поставить нельзя.** Победителем должен быть отмечен один из соперников.

### UI (по скриншотам)
- `57--...Скрин8.png`: расширенное окно встречи. Заголовок этапа «Финал 1», спиннер стола без надписи.
  - `Кацман Лев [W] : [L] Овчаров Дмитрий`, W на зелёном фоне, L на красном. Видны **полные имена**.
  - Ниже **таблица счёта по партиям**: колонки `1 2 3 4 5 6 7`, строки `Кацман Л` и `Овчаров Д`, ячейки пустые. Можно вписать очки каждой партии, до 7 партий.
  - Слева кнопки быстрого счёта `3:0`, `3:1`, `3:2`, **`W:L`**, справа `0:3`, `1:3`, `2:3`, **`L:W`**.
  - По центру кнопка **«Отменить игру»**.
  - `OK` / `Отмена`.

### Механика/правила
- Результат встречи бывает:
  - обычный: партии `a:b`, где у победителя N партий;
  - технический: `W:L` или `L:W`.
- Техническая победа исключается из расчёта рейтинга, но в турнирной таблице считается как победа (используется для продвижения, см. 8.6 и 7.8).
- Набор быстрых кнопок строится от N: при «до 3 побед» это 3:0, 3:1, 3:2, W:L и зеркальные.
- Счёт по партиям (очки 11:9 и т.п.) вводить необязательно. В расчётах мест, судя по 8.8, мячи не используются.

## 7.9. Вкупление в 1-й финал (ID 60)

### Текст
- Применяется в схеме «Группы + два финала». Игрок, по итогам групп попавший во 2-й финал, принудительно включается в 1-й финал. Обычно это платная услуга организатора, о ней объявляют до турнира.
- Пример: 28 участников, 7 групп по 4. Места 1–2 идут в 1-й финал, это 14 человек. Места 3–4 идут во 2-й финал. 1-й финал делают на 16, добавляя 2 вкупившихся.
- Как сделать: вкладка «Игроки», перетащить игрока в блок **«Попадают в 1-й финал»**.
- Можно сделать **в любой момент группового этапа**, не дожидаясь его конца, но **обязательно до начала 1-го и 2-го финалов**.
- Вкупившийся по умолчанию **сеется последним номером** в 1-м финале. Посев можно поменять вручную (8.2).

### UI (по скриншотам)
- `60--img_content_25_07-016.png`: та же вкладка «Игроки». `Зоненко В` перетащен в «Попадают в 1-й финал», в «Снялись с турнира» остаётся `Буров В`.

### Механика/правила
- Список «принудительно в 1-й финал» заполняется до старта финалов. При формировании финалов такой игрок исключается из распределения по местам группы во 2-й финал и добавляется в 1-й финал последним посевом.
- Размер сетки 1-го финала растёт на число вкупившихся. Пустые места превращаются в «баи» с автоматическим `W`.

## 8.3. Изменить схему этапа (ID 67)

### Текст
- Схему можно менять во время турнира, **если этот этап ещё не стартовал**.

## 8.6. Запуск игр финалов до окончания групп (ID 75)

### Текст
- **Программа не даёт начать 2-й этап до окончания групп**, то есть до записи результата последнего группового матча.
- Обходной путь: когда остались последние встречи, поставить в них **технические победы** (например, сильнейшему или ведущему в счёте). Программа сформирует сетку финала, и финальный этап можно начинать. Матчи, на которые могут повлиять незаконченные игры, вызывать не нужно.
- Когда встречи доиграют, вместо технических побед ставят реальные результаты.
- Если места в группе распределились иначе, игроков в финальной сетке **меняют вручную**: ПКМ по сетке → «поменять местами».

### Механика/правила
- Следующий этап формируется **автоматически** в момент, когда все встречи предыдущего этапа имеют результат.
- Правка результата в группе после формирования финала разрешена, **но финал автоматически не перестраивается**, синхронизация делается вручную.
- Это ограничение TM: частичного старта финала нет. Для нас это возможность сделать лучше: формировать финал частично по группам, которые уже доиграли.

## 8.7. Перезапуск программы при сбое (ID 95)

## 8.8. Места в группе не расставились автоматически (ID 110)

### Текст
- Если у нескольких человек в группе **все параметры равны**, программа не может распределить места. Такие места **подсвечиваются красным**.
- Если это **завершающий** этап, можно так оставить: в итоговом протоколе у них будет **одно и то же место**.
- Если дальше идёт ещё этап, **программа не даст его начать**, пока места не распределены. Способы разрешить:
  - дополнительная партия между игроками;
  - один «баланс» до двух очков;
  - жеребьёвка.
- Двойной клик по красному месту открывает окно редактирования. Выбрать участника и нажимать «UP» / «DOWN» для каждого.
- После этого места становятся **оранжевыми**: это значит, что они распределены вручную.

### Механика/правила

## 9.1. Варианты посева в группы (ID 61)

### Текст
Пример: 16 игроков с рейтингами от 100 до 1600, 4 группы.

- **Равномерный**: внутри группы игроки распределены равномерно. Используется для ускорения групп, так как меньше принципиальных игр между близкими по рейтингу.
  - Гр1: 1600, 1200, 800, 400
  - Гр2: 1500, 1100, 700, 300
  - Гр3: 1400, 1000, 600, 200
  - Гр4: 1300, 900, 500, 100
- **Змейкой**: группы примерно равны по силе. Самый справедливый вариант, чаще всего используется.
  - Гр1: 1600, 900, 800, 100
  - Гр2: 1500, 1000, 700, 200
  - Гр3: 1400, 1100, 600, 300
  - Гр4: 1300, 1200, 500, 400
- **По рейтингу**: подряд от сильнейшего к слабейшему. Самые сильные попадают в 1-ю группу, слабейшие в последнюю. Используется для объединения нескольких лиг или классов в одном турнире.
  - В статье пример с опечаткой (Гр1: 1600, 1500, 1300, 1200 — пропущен 1400; Гр4 повторяет 400).
  - Логически: Гр1: 1600–1300, Гр2: 1200–900, Гр3: 800–500, Гр4: 400–100.

### UI
Скриншотов нет. Варианты в окне схемы: `змейкой`, `равномерный`, `по рейтингу`, `змейкой модиф.`, `классы`.

### Механика/правила
Игроки отсортированы по рейтингу по убыванию, индекс i от 0, G групп.
- **Равномерный**: группа = `i mod G`, каждый «ряд» идёт слева направо.
- **Змейка**: ряд `r = i div G`; при чётном r группа = `i mod G`, при нечётном `G-1-(i mod G)`.
- **По рейтингу**: группа = `i div size`, то есть блоками.
- **Змейкой модиф.** и **классы** в статьях не описаны.
  - «Классы», видимо, связаны со схемой «Группы (по типу лиг-классов)».
  - «Модифицированная змейка», видимо, учитывает игроков из одного клуба или города **[неизвестно]**.
- В группе игроки нумеруются по рейтингу: строка 1 — сильнейший. Превью из 8.3 показывает Участник16 первой строкой.

## 9.3. Выбывание после N поражений (ID 63)

### Текст
- Правило «выбывание после N поражений» добавляется к любому типу сетки в окне редактирования схемы, в параметрах сетки.
- **Single Elimination** (чистая олимпийка): выбывание после 1-го поражения.
- **Double Elimination** («двухминуска»): выбывание после 2 поражений.
- Пример: прил. 12 + выбывание после 2 поражений, 16 игроков.

### UI (по скриншотам)

### Механика/правила
- N ограничивает число поражений игрока. Встречи, где участвуют только игроки с N поражениями, вырезаются из протокола.
- Итоговые места выбывших делятся диапазонами, например все проигравшие во встречах 16–19 получают «13–16» **[вывод, явно не сказано]**.
- N = 0 означает без ограничения, то есть полная сетка на все места.
- N = 1 + прил. 11 даёт олимпийку. Опция «игра за 3-е» оставляет встречу за 3–4.

## 9.4. Распределение мест в группе (ID 64)

### Текст
- При равенстве очков у нескольких игроков по правилам НТ (ст. 4.2) последовательно сравнивают:
  1. **очки во встречах этих игроков между собой**;
  2. **отношение** выигранных и проигранных партий во встречах этих игроков между собой.
- Результаты встреч с остальными участниками группы **не учитываются**.
- **Пример 1** («треугольник» Ливенцов, Кривошеев, Зоненко, у каждого 1–1 между собой). Отношение партий: Ливенцов 5/3 = 1.66 (2-е), Зоненко 4/5 = 0.8 (3-е), Кривошеев 3/4 = 0.75 (4-е). Частая ошибка: учитывать встречи вне треугольника (против Скачкова).
- **Пример 2** (Каракашевич, Буров, Куимов). Каракашевич 4/3 = 1.33 (1-е), Куимов 5/4 = 1.25 (2-е, в статье округлено до 1.2), Буров 3/5 = 0.6 (3-е). Частая ошибка: считать **разность**, а не **отношение**. У Каракашевича и Куимова разность одинаковая (+1), но 4/3 > 5/4.
- **Пример 3** (группа на 6, четверо с равными очками). Очки только между ними: Сидоренко 4, Скачков 4, Шибаев 5, Власов 5. Четвёрка распалась на две пары, в каждой снова сравниваются очки, то есть личная встреча. Итог: Власов 3, Шибаев 4, Сидоренко 5, Скачков 6. Частая ошибка: сразу переходить к отношению партий, пропуская очки в мини-турнире.

- `64--09-007.png`: группа 1. Скачков 6 (М 1), Ливенцов 4 (2), Кривошеев 4 (4), Зоненко 4 (3). Блок встреч троих обведён красной рамкой.

### Механика/правила (алгоритм)
1. Основная сортировка по очкам О (победа = 2, поражение = 1). Как считается техпоражение, в статьях не сказано. **[вывод]** Вероятно, W/L = 2/1 или 2/0, нужно проверить.
2. Для каждого множества игроков с равными очками строится **мини-таблица только из встреч между ними**:
   - a. сортировка по очкам в мини-таблице;
   - b. если остались равные, к ним **рекурсивно** применяется шаг 2: новая мини-таблица только из встреч этого подмножества (пример 3);
   - c. если подмножество не распалось по очкам, сравнивается **отношение** партий (выигранные/проигранные) в мини-таблице. Деление на ноль означает бесконечность.
3. Мячи (очки внутри партий) не используются. Если равенство сохраняется, это конфликт: места красные, нужна ручная расстановка через «Редактор конфликта занятых мест», после неё места оранжевые.

**[вывод]** Порядок шагов b и c, видимо, такой: если очки в мини-таблице разделили группу на подгруппы, каждая подгруппа проходит алгоритм заново с очков. Отношение партий берётся, только когда очки в текущей мини-таблице равны у всех.

# Как выглядит интерфейс TM (сводно)

## Главное окно во время турнира
- **Заголовок**: `<файл>.rttf - Турнир-менеджер RTTF*`.
- **Меню**: `Турнир` (новый, Открыть... Ctrl+O, …), `Схема` (Изменить схему этапа; Изменить распределение игроков по финалам; выбор схемы турнира), `Тип турнира` (в новой версии вместо `Рейтинг`), `Экспорт результатов`, `Настройки`, `Справка`.
- **Левая большая область**: картинка активного этапа (группы-таблицы или сетка) на светло-сером фоне с прокруткой. Для сеток сверху чекбокс «Скрывать пустые участки сетки».
- **Вкладки внизу слева**: `Игроки | <этап 1> | <этап 2> | … | Результаты турнира`. Названия этапов: «Группы», «Сетка», «Финал 1» и т.п.
- **Правая колонка**:
  - вверху панель **«Играется»** с лупой поиска. Строки: `стол` (зелёный фон) | `этап` (жёлтый: `Гр(3)`, `С`, `1 фин.`) | `минуты` (розовый: `4 м`) | `Игрок A : Игрок B`;
  - внизу панель **«В ожидании»** с лупой. Слева вертикальный столбец «Столы» с кнопками `1…N`, занятые столы с красной цифрой. Строки: `этап` (жёлтый) | `(ожид.м) Игрок A : Игрок B (ожид.м)`. Красная строка означает, что игрок занят; `???` означает, что соперник не определён. Выбранная строка синяя.
- **Нижняя панель**: слева «Второй монитор :» и кнопки по числу этапов (активная голубая), справа «Онлайн трансляция:» с иконками ⚙, ▶ / `II`, ✓ / ✗.

## Вкладка «Игроки»
- Тулбар: Добавить игрока (▾ меню), Редактировать, Удалить (неактивно после старта), `БД` ▾ (база рейтинга), флаг (старт/финиш?).
- Таблица: `№ | ID | Фамилия, Имя, Отчество | Рейтинг | Оплатил | Год рождения | Город`. Сортировка кликом по заголовку.
- Справа три drop-зоны: «Попадают в 1-й финал», «Снялись с турнира», «Играют вне зачета». В них перетаскивают игроков (drag & drop).
- ПКМ по игроку: «добавить в этап..» (для опоздавших).

## Картинка группы
- Шапка: номер группы (тёмно-синяя ячейка с белой цифрой) | «Участник» | `1..n` | `О` | `М`. Голубой фон шапки.
- Строка: номер | Фамилия И | `R:1409` (тёмно-красный мелкий) | ячейки результатов (диагональ заштрихована) | очки | место.
- Ячейка результата:
  - зелёная `3 : 1` — победа игрока строки;
  - красная `1 : 3` — поражение;
  - жёлтая `6 ст / 10 м` — идёт на столе 6, 10 минут;
  - пустая белая — не сыграна.
- Место: обычное; **красное** — конфликт, не распределено; **оранжевое** — распределено вручную.
- ПКМ: Добавить... / Удалить / Редактировать... / Поменять местами... / Уменьшить масштаб / Увеличить масштаб.

## Картинка сетки
- Плашки раундов (голубые): `1 / 8`, `1 / 4`, `1 / 2`, `ФИНАЛ`, диапазоны мест `3 .. 4`, `5 .. 8`, `9 .. 16`, ….
- Встреча — прямоугольник из двух строк: имя, рейтинг `R:`, ячейка счёта, справа серый квадрат с номером встречи. Соединительные линии. Слева номер посева (в первом раунде) или `-N` (проигравший встречи N).
- После групп у игрока префикс места в группе: `1) Сидоренко В`.
- Идущая встреча: жёлтый фон, красный текст `4ст` / `5м`. Сыгранная: победитель **жирным**, партии красными цифрами. Пустой соперник: у игрока `W`.
- ПКМ: «Поменять местами игроков... ▸» / Уменьшить / Увеличить масштаб.

## Вызов встречи и ввод результата
- Окно **«Редактирование встречи»**:
  - «Стол N» ▲▼ и название этапа;
  - Игрок A ▲▼ [счёт] : [счёт] ▲▼ Игрок B. Фон: красный — проигравший, зелёный — победитель, белый — нет результата / «обнуление»;
  - расширенный вид: сетка очков по партиям `1..7` для двух игроков; кнопки `3:0`, `3:1`, `3:2`, `W:L` слева и `0:3`, `1:3`, `2:3`, `L:W` справа; «Отменить игру»;
  - `OK` / `Отмена`.
- Вызов: пара + стол; двойной клик в «В ожидании»; клик по встрече на картинке. Стол по умолчанию первый свободный.
- Ввод: ▲ у проигравшего (первый клик = 0:N, далее +1), либо быстрые кнопки.
- ПКМ в «Играется»: «Отменить игру», «Добавить игру вне турнира ▸ игрок ▸ соперник».

## Столы и время
- Число столов задаётся в настройках. Столбец «Столы» показывает кнопки, красные означают занятые.
- У встречи: номер стола и минуты с начала. У игрока в очереди: минуты ожидания в скобках.

## Народный монитор
- Отдельное окно «Народный монитор»: слева заголовок этапа и картинка этапа, справа «Дельта рейтинга» (игроки по алфавиту, дельта: зелёная ≥0, красная <0).
- Этап выбирается кнопкой «Второй монитор». На основном экране пунктиром показана видимая область. Масштаб независимый.

## Настройки трансляции и программы
- «Настройки программы»: Общие / Сетки / Список игроков / Взнос и призовой фонд / Результаты турнира / Онлайн трансляция (логин, пароль).
- ID турнира задаётся окном «Идентификатор турнира:» по кнопке ⚙.

## Редактор схемы
- «Редактирование схемы проведения турнира»: Название; Предполагаемое кол-во игроков; дерево этапов (+/−); Тип этапа; для групп Формирование / Посев / Очередность; для сетки Тип сетки / игра за 3-е / Смешаная N / Выбывание после N поражений. Справа живое превью.
- «Схема этапа турнира» (распределение): матрица Место × (k фин. / Вылет).
- «Редактирование сохраненного списка схем турниров»: список шаблонов, Добавить / Удалить / Изменить / Копировать / Импорт / Экспорт.

## Экспорт
- Меню «Экспорт результатов»: снимок этапа, все этапы одним изображением, список завершённых игр, список мест, Отправить результаты на сайт, Экспортировать лог-файл.
- Окно «Информация о турнире»: Ссылка на турнир, Корректировка ☐, Дата и время начала, Клуб, Название турнира, Комментарий.

- [ ] Смена стола у идущей встречи в любой момент

- [ ] Таймер встречи (минуты с вызова) в панели и на картинке («N ст / M м»)

## Результаты
- [ ] Окно «Редактирование встречи»: стол, этап, счёт двух игроков
- [ ] Ввод счёта «от проигравшего» (▲ у проигравшего: 0:N, 1:N, …)
- [ ] Быстрые кнопки 3:0 / 3:1 / 3:2 / W:L и зеркальные
- [ ] Опциональный ввод очков по партиям (до 7 партий)
- [ ] Формат матча «Игра до N побед» (по умолчанию 3)
- [ ] Цвет поля счёта: зелёный — победитель, красный — проигравший, белый — нет результата
- [ ] Отмена начатой игры (ПКМ «Отменить игру» / кнопка в окне), встреча возвращается в очередь
- [ ] Отмена завершённой игры обнулением счёта
- [ ] Редактирование результата в любой момент
- [ ] Техническая победа W:L / L:W, без влияния на рейтинг
- [ ] Запрет технического результата обоим (W:W считается «обнулением»)
- [ ] Предупреждение перед последней игрой («Оповещать перед посл. игрой»)

## Изменения по ходу турнира
- [ ] Снятие игрока перетаскиванием в «Снялись с турнира», авто-техпоражения во всех оставшихся встречах
- [ ] Статус «Играют вне зачета»
- [ ] Вкупление: «Попадают в 1-й финал», в любой момент групп до старта финалов
- [ ] Вкупившийся сеется последним номером в 1-м финале
- [ ] Внетурнирная рейтинговая встреча между не играющими сейчас участниками (ПКМ в «Играется» → игрок → соперник)
- [ ] Внетурнирная встреча без метки этапа, правится только во вкладке «Результаты турнира»
- [ ] Опоздавший: повторный выбор схемы сбрасывает встречи, игроки остаются
- [ ] Опоздавший: «добавить в этап..» в любой этап, в группу встаёт по рейтингу, сыгранные встречи сохраняются
- [ ] Игрока, добавленного после старта, нельзя удалить, только заменить
- [ ] Опция «Двойной клик по игроку — Заменить, а не Редактировать»
- [ ] Обмен игроков в группе / между группами (окно «Выбор игрока группы для замены X» с деревом групп и превью)
- [ ] Обмен игроков в сетке (ПКМ → «Поменять местами игроков...» → игрок → второй игрок)
- [ ] Обмен игроков между разными финалами (подменю «Финал 2 ▸»)
- [ ] Обмен разрешён только до вызова первой встречи этапа
- [ ] Изменение схемы этапа («Схема → Изменить схему этапа»), только если этап не стартовал
- [ ] Изменение распределения по финалам (матрица Место × Финал k / Вылет) до вызова первой встречи любого финала
- [ ] Масштаб картинки этапа: уменьшить / увеличить (ПКМ)
- [ ] Следующий этап формируется только после записи последнего результата предыдущего (TM)
- [ ] Обход TM: техпобеды → старт финала → реальные результаты → ручной обмен (финал не пересобирается автоматически)

- [ ] Формирование групп: по кол-ву групп / по кол-ву игроков в группе
- [ ] Посев: змейкой (по умолчанию в примере)
- [ ] Посев: равномерный

- [ ] Строки в группе упорядочены по рейтингу

## Места в группе
- [ ] Очки: победа 2, поражение 1
- [ ] Тай-брейк 1: очки только во встречах между равными
- [ ] Рекурсивное применение к подгруппам, оставшимся равными

- [ ] Мячи не учитываются
- [ ] Нерешённое равенство показано красным

- [ ] При следующем этапе нерешённое равенство блокирует его старт
- [ ] «Редактор конфликта занятых мест» (Top / Up / Down / Bottom)
