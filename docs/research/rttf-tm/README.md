## 1. Как устроен RTTF TM

Это настольная программа для Windows (WinForms). Её выдают по письму, первый запуск требует ключа активации. Турнир хранится в файле `.rttf`, примерно каждые 10 секунд пишется автосохранение.

**Главное окно** собрано из одного экрана:

```
┌ Меню: Турнир | Схема | Тип турнира | Экспорт результатов | Настройки | Справка ─────────┐
│ [+участник ▾] [ред.] [удал.] [БД ▾] [🏁 старт]                                          │
├──────────────────────────────────────────────────┬───────────────────────────────────────┤
│                                                  │ ИГРАЕТСЯ                          🔍  │
│  Картинка текущего этапа:                        │ 1 │ С │ 11м │ Кривошеев В : Ливенцов А │
│  матрицы групп (зелёный = победа,                │ 2 │ Гр(3) │ 6м │ …                     │
│  красный = поражение, «R:478» под фамилией)      ├───────────────────────────────────────┤
│  или сетка с номерами встреч, «-N» = проигравший │ В ОЖИДАНИИ                        🔍  │
│  встречи N, плашки «1/4», «3 .. 8»               │ С │ Гр(1) │ (61м) Радченко А : Зайцев П │
│  Идущая встреча прямо в клетке: «6 ст / 10 м»    │ Т │ Гр(3) │ Беляков В : Тарасов А (69м) │
│                                                  │ о │ …  красные = игрок занят          │
│                                                  │ л │ «??? : Игрок» = соперник неизвестен│
│                                                  │ ы │ кнопки столов 1..N сбоку          │
├──────────────────────────────────────────────────┴───────────────────────────────────────┤
│ Вкладки: Игроки | Группы | Финал 1 | Финал 2 | Результаты турнира                        │
│ Второй монитор: [Группы] [Финал 1] [Финал 2]        Онлайн трансляция: ⚙ ▶ ✓/✗          │
└──────────────────────────────────────────────────────────────────────────────────────────┘
```

**Цикл работы.** Выбрать схему, зарегистрировать игроков, задать настройки и включить трансляцию. Дальше вызывать встречи на столы и записывать счёт. Последний результат сам отправляет итоги на сайт, рейтинг появляется в течение 5 минут.

**Сильные стороны, которые нужно повторить:**

1. **Плотность информации.** Всё на одном экране: картинка этапа, кто играет, кто ждёт, сколько минут ждёт каждый игрок, какие столы свободны. Ничего не прячется в диалоги.
2. **Ввод счёта за 1–2 клика.** Кнопки `3:0 3:1 3:2 W:L` и зеркальные, стрелки «от проигравшего». Очки по партиям вводятся по желанию.
3. **Три способа вызвать встречу:** клик по паре и по столу, двойной клик с первым свободным столом по умолчанию, клик по встрече прямо на картинке этапа.
4. **Гибкость по ходу турнира.** Опоздавшего можно «добавить в этап» в любой момент: в группу он встаёт по рейтингу, сыгранное сохраняется. Снявшемуся автоматически ставятся техпоражения. Игроков можно поменять местами в группах, сетках и между финалами. Есть вкупление в 1-й финал, внетурнирная встреча на рейтинг, смена схемы этапа и правка распределения по финалам.
5. **Форматы.** Сетка с розыгрышем **всех** мест: утешительная ветка «3..N» и классификация 5–6, 7–8, 9–12 и далее. Выбывание после N поражений, так что double elimination получается одной настройкой. Финалы вкруг **с зачётом**: встречи из групп переносятся. Два финала после групп. Библиотека схем с экспортом и импортом.
6. **Зрители.** «Народный монитор» на втором экране с дельтами рейтинга. Трансляция на сайт в реальном времени с блоком «Турниры LIVE».
7. **Деньги.** Взнос, отметка «Оплатил», расчёт призового фонда в процентах с округлением.

**Слабые стороны, на которых мы выигрываем:**

| Слабость RTTF TM                                                                                                                               | Что у нас                                                                      |
| ---------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------ |
| Только Windows, установка, ключ активации, программа выдаётся по письму                                                                        | Веб и PWA: телефон, планшет, ноутбук, ничего не надо ставить                   |
| Один оператор на файл, второй ноутбук невозможен                                                                                               | Несколько операторов одновременно, конфликты решает порядок операций (ADR-026) |
| Восстановление после сбоя руками: найти автосохранение, сверить со скриншотом, переименовать файл                                              | Сервер и офлайн-очередь на диске, ничего не теряется                           |
| Без интернета нет трансляции, правки через сайт возможны только 12 часов, дальше через экспорт с флагом «Корректировка» и модерацию до 3 суток | Результат публикуется в момент ввода, офлайн досинхронизируется сам            |

## 2. Матрица паритета

Легенда: ✅ есть · 🟡 частично · ❌ нет. Приоритет: **P0** — без этого клуб не перейдёт; **P1** — нужно для паритета; **P2** — лучше, чем у них, или редкий случай.

## 5. План доработок

Порядок выбран так, чтобы после каждого шага клуб мог провести настоящий турнир без обходных путей.

### Этап A. Чиним то, что ломает обычный турнир (P0, баги)

1. Баги 1–5 из раздела 3.
2. Кнопки в консоли: «Снять игрока» (группа и сетка: в группе техпоражения по ADR-009, в сетке соперник проходит дальше), «Неявка», «Отказ по ходу встречи».
3. Настройки в ходе турнира: число столов в любой момент, длина встреч для ещё не начатых кругов.

### Этап B. Гибкость по ходу турнира (P0)

4. **Поздняя запись и «добавить в этап»:** организатор добавляет игрока после закрытия записи и после старта. В группе игрок встаёт по рейтингу, ему создаются встречи с остальными, сыгранное сохраняется. ADR: какие этапы допускают вставку (группа — да; сетка — только в свободный слот или бай до его первой встречи).
5. **Замена игрока** в незавершённых встречах этапа.
6. **Новый игрок прямо из формы турнира** с оценочным рейтингом для посева (закрыть ОВ-2).
7. **Отметка «Оплатил»** (закрыть ОВ-6).

### Этап C. Форматы, без которых клуб не уйдёт с RTTF (P0–P1)

8. **Сетка с розыгрышем всех мест** (прил. 11): ветка «3..N» и классификационные блоки. Новый построитель в `brackets`, стратегия мест, отрисовка. Закрыть ОВ-15 решением «все проигравшие», как у RTTF.
9. **N финалов после групп:** матрица «место в группе → Финал k / вылет», каждый финал со своей схемой (сетка или круг). Обобщает ADR-045.
10. **Финалы вкруг с зачётом:** перенос встреч из групп.
11. Прил. 12 и выбывание после N поражений.

### Этап D. Скорость работы в зале (P1)

12. Минуты ожидания каждого игрока в очереди, вызов кликом по клетке матрицы и по встрече сетки, горячие клавиши.
13. Обмен игроков до первой вызванной встречи этапа (а не только в REG_CLOSED). Редактор распределения по финалам.
14. Журнал действий консоли с откатом последних шагов.
15. Оценка времени до конца турнира.

### Этап E. Публикация и зрители (P1)

16. Живая страница турнира по SSE, счёт по партиям, блок «Сейчас идут» на главной.
17. Живая дельта рейтинга на ТВ-экране и странице турнира.
18. Экспорт: PNG этапа, карточка итогов для соцсетей, печать протоколов.
19. **Корректировка после публикации** с пересчётом рейтинга по журналу (это ещё и P0 для доверия).
20. Калькулятор призового фонда.

### Этап F. Лучше, чем у RTTF (P2)

21. Запуск финала по готовности групп.
22. Общий пул столов на несколько турниров дня.
23. Библиотека схем клуба.
24. Автоназначение столов (опция), «решающая встреча», внетурнирные встречи, вкупление, дополнительные варианты посева.
